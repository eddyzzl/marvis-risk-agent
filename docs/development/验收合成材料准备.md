# 验收合成材料准备

此说明只准备 S12/S13 的公开合成 SQL 来源，不使用历史客户材料、机构连接或真实凭据，也不提供正式冻结验收答案。每次生成独立目录；不覆盖已有工作区或 `sql_sources.json`。其他检查所需的 Notebook、PMML、独立 OOT、签名和授权仍按各自合同准备，不能用这三行合成数据替代。

## 1. 创建本地 SQL 来源

在已安装本次验收版本的 Python 环境中执行下面整段命令。脚本只创建新目录和三个合成记录，不联网、不配置模型、不读取现有业务文件。先记录 `python -m marvis version` 的输出，再使用同一环境启动服务。

```bash
python - <<'PY'
from datetime import datetime, timezone
import json
from pathlib import Path
import shlex
import sqlite3
from uuid import uuid4

root = Path.home() / "MARVIS-验收材料" / (
    datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ") + "-" + uuid4().hex[:8]
)
root.mkdir(parents=True, mode=0o700, exist_ok=False)
workspace = root / "workspace"
materials = root / "materials"
sources = root / "sources"
for directory in (workspace, materials, sources):
    directory.mkdir(mode=0o700)
source = sources / "synthetic.sqlite"
with sqlite3.connect(source) as connection:
    connection.execute(
        "CREATE TABLE applications (channel TEXT, amount INTEGER, bad INTEGER)"
    )
    connection.executemany(
        "INSERT INTO applications VALUES (?, ?, ?)",
        [("alpha", 1000, 0), ("alpha", 3000, 1), ("branch", 2000, 0)],
    )
    connection.commit()
with (workspace / "sql_sources.json").open("x", encoding="utf-8") as config:
    json.dump(
        {"synthetic-acceptance": {"backend": "sqlite", "path": str(source.resolve())}},
        config, ensure_ascii=False, indent=2,
    )
print("新验收工作区：", workspace)
print("创建任务时的材料目录：", materials)
print("合成数据库：", source)
print("启动命令：")
print("python -m marvis serve --workspace " + shlex.quote(str(workspace))
      + " --host 127.0.0.1 --port 8860")
PY
```

脚本输出的工作区才是本次 S12/S13 的工作区。选择空闲端口后，从同一候选目录运行输出的启动命令；不要把来源配置复制或合并到日常工作区。数据库在工作区外的同批次 `sources` 目录中，平台按本地配置以只读方式连接。

合法配置的结构如下，实际路径已由上面的脚本填写。此例用于默认本地参考模式；机构模式下还需原生身份、任务及数据权限。需要限制来源主体时，由管理员在本地配置 `allowed_actor_ids` 为真实登记的主体 ID，不能用名字或客户端自报角色替代。

```json
{
  "synthetic-acceptance": {
    "backend": "sqlite",
    "path": "/本次新目录/sources/synthetic.sqlite"
  }
}
```

本例没有数据库账户和密码。不要把机构 DSN、密码、连接文件或真实路径发给 Agent，也不要把它们写入验收记录。无配置时页面显示“没有已配置来源”；非法或越权来源应显示不可用及原因，不能从列表静默消失。

## 2. 在应用内检查 S12/S13

1. 打开该服务，在左侧点击“新建任务”，在任务类型页点击“数据处理”。在“创建数据处理任务”对话框填写任务名称、负责人，选择“文件路径”并在“数据材料目录”填写脚本输出的 `materials`，勾选“手动模式”，点击“创建任务”。进入该任务工作台后操作 SQL 控件，不确认无材料的 JOIN 提案。
2. 选择该任务，进入数据工作区，展开“从 SQL 数据源导入”，点击“重新读取来源”。应看到 `synthetic-acceptance` 和表 `applications` 的三个字段；没有来源时先检查启动命令使用的工作区和其中的 `sql_sources.json`。
3. 选择“手动 SELECT”，粘贴下列查询并点击“生成待确认查询”。此时只能看到待确认的 SQL，不应已经导入数据。
4. 核对后点击“确认查询并导入”。“导入结果预览”应显示两行及当前数据集、工作区版本和完整内容指纹；分类字段按平台隐私规则显示稳定的脱敏标记，数值列保持可核对。点击“下载结果数据集”，文件保存前应核对当前版本和 SHA-256；下载 Parquet 保留原数据。在本机读取下载文件，核对下面的两行、列名与数值；保留数据集版本、来源和产物摘要。取消结果读取或切换任务后，迟到结果不能覆盖当前页面；权限被撤销时不能继续使用旧下载控件。

```sql
SELECT channel, COUNT(*) AS n, AVG(amount) AS mean_amount
FROM applications
WHERE amount >= 2000
GROUP BY channel
ORDER BY channel
```

这三行合成记录的下载文件应产生 `alpha / 1 / 3000` 和 `branch / 1 / 2000` 两行；预览中的 channel 为脱敏标记，n 和 mean_amount 应分别是 `1 / 3000`、`1 / 2000`。它们是公开演示材料的可复算结果，不是机构指标或隐藏验收答案。需要在本机读取 Parquet 时，可用已安装 pandas 的环境执行 `python -c 'import pandas as pd; print(pd.read_parquet("下载文件的实际路径"))'`；仅用于这份合成文件，不把真实明细粘贴到验收记录或 Agent。

5. 再选“自然语言”，输入“从 applications 中筛选 amount 大于等于 2000，按 channel 分组，统计条数并计算平均 amount，按 channel 排序”。这一分支需要你已经批准并在本机配置的模型；先核对待确认 SQL，再确认导入。不配置模型时应明确提示；不得将手动查询通过记作自然语言分支已验收。
6. 用新的提案尝试 `DELETE FROM applications`、多条语句和不支持的语法；应在执行前明确拒绝。核对源库仍为原三行。权限、超时、行数上限需分别准备相应本地配置和足量合成数据，三行材料不覆盖这些检查。
7. 在生成提案后改变当前工作区版本，再确认旧提案；应拒绝旧版本。确认已完成的原请求只读回同一数据集。若执行开始后失败或状态未知，保留原状态，不能用同一提案隐式重新查询；按页面下一操作显式生成新提案。

当前查询合同支持单表 SELECT、投影、COUNT/SUM/AVG/MIN/MAX、AND 筛选、分组、排序和 LIMIT；其他语法应澄清或拒绝。S12/S13 的完整结论需要手动、自然语言和各负例分别有原件，不能用此演示替代整行验收。

## 3. 其他材料与入口

- 模型验证：按 [Notebook 契约](../notebook_contract.md) 和 [开发人员提交要求](../对notebook的要求.md) 准备 Notebook、PMML 和必填 importance 的字典。
- 历史映射：策略任务的材料目录中放入完全合成的 UTF-8 CSV、静态 XLSX 或明确结构的 JSON；在“项目现状与历史材料”填写截止日和相对文件名、固化上下文，再展开“确认历史材料中的字段和指标”。选择精确来源位置、指标/期间/版本并确认。任意文档或模型文件不能直接当作可定位指标；无法解析时须按提示整理静态表，未知保持未知。
- 盲 OOT：另建空白建模任务，使用全新未暴露的独立 Parquet。保管、开发和评估人员使用各自已绑定的独立会话；先封存，再仅登记 train/test 开发材料、训练并冻结，最后由评估人员评估一次。不能复用已开始开发的任务、S15 的普通 OOT 或历史比较已消费的材料。
- 身份与交接：使用设置中的“身份与资源授权”“跨实例交接”，遵守 [身份与同步运行说明](../institution-identity-and-sync.md)。参考主体和签发方只证明本地软件流程，不能充当机构认证。
- 签名能力与隔离：使用“签名与版本”和执行环境设置，遵守 [签名能力合同](../governed-capability-contract.md) 与 [隔离运行说明](../native-worker-isolation.md)。非支持权限或平台应拒绝，不能为了验收成功退回宽松执行。
