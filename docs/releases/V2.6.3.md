# MARVIS V2.6.3

本次发布将 V2.5.0 之后已落地的软件能力更新到公开 V2 主线。功能交付和参考环境运行不代表历史业务或机构生产验收；审计整改计划继续进行。

## 发布安装修复

- 明确声明并锁定 XML 安全解析依赖及原件复核入口使用的 HTTP 客户端依赖。干净安装后的 PMML 原件检查及 Excel 单元格独立复核可正常调用，继续拒绝 DTD、实体和外部扩展。
- 取消请求回归为真实服务启动保留时间，仍核对请求已发出、运行被预算中断、工作区被清理以及评分未通过；完整回归继续覆盖该场景。
- 为实测接近原超时上限的 Linux 快速回归组增加运行余量，未移除测试或放宽业务断言。
- 修正并发转换回归中的时序假设：较晚启动的旧请求可在活动数据集检查处被拒绝，也可在提交时因工作区版本过期被拒绝。测试覆盖提交后的迟到请求，并核对唯一结果、文件摘要、单次版本和分析代际递增；生产执行逻辑及业务断言不变。
- V2.6.0 的远端回归发现 XML 依赖缺失；V2.6.1 的默认安装检查进一步发现原件复核入口仍依赖开发依赖中的 HTTP 客户端；V2.6.2 的全量回归发现上述并发测试的时序假设。三个 Release 均保留为未发布草稿，已推送标签保持不变。本次补丁版交付修复和以下全部能力。

## 新增能力

- 业务目标、采用对象与确定性验收状态贯通 API、Agent、工作台和报告，区分达标、不达标及证据不足。
- 本地在线决策服务支持认证模型/规则包、审批安装、版本读回、激活、影子环境、幂等决定和回滚。
- 默认监控调度接入真实执行器，支持本地通知、已读、停用恢复、诊断与重新评估。
- 历史决策回放支持时点数据、事件特征、时间窗口比较和现金流对账；催收工作台接入政策、数据映射、审批与本地参考执行。
- 数据准备、筛选、交叉验证、调参与最终训练传递原生来源和实际成员证据，拒绝已识别的未来信息及评估成员泄漏。
- 验证、标签、普通 JOIN、部分组合分析及基础特征指标增加有明确范围的独立原件复核。报告登记、受保护下载与实际文件摘要绑定。
- 评测记录模型调用、部分工具、排队、计划修订和确认等待；缺失测量保留未知。

## 修复与架构整理

- 两个共享全局命名空间包改为正常模块依赖；重复业务辅助逻辑收敛。
- 任务与模型访问代际、操作租约和报告版本比较保护晚到响应、重复操作及并发编辑。
- 不确定执行结果从原生产者核对后续执行，避免盲目重跑副作用。
- 修复并列分数 KS、非有限评分、分箱区间、JOIN 新增列计数、组合月份/身份/金额约束及 Excel 错误样式文本。
- JUnit 证据以单一有界解析器构建树，拒绝 DTD、实体及过深结构。
- 已选择模型移交验证后仍可进入监控；平台重新核对已提交的选择记录和模型来源，阻止未经选择的移交模型进入该流程；传统重训后的实际交付模型也写入选择记录。
- 更新 Tornado 依赖，修复锁定依赖图中已知的安全漏洞；完整远端回归按稳定测试身份分为四组，覆盖全部测试层级。

## 发布边界

- 未完成的结构化 LLM 出站迁移保留在开发分支；本版本未声明全调用链外发保护已经完成。部署前应根据实际模型配置和数据制度审查可发送内容。
- 新增 Notebook 进程网络隔离目前只有 macOS 实现。该迁移保留在开发分支，本版本继续使用既有跨平台 Notebook 执行契约。
- 盲 OOT 独立封存、完整耗时测量、全部工作流/边界/恢复复核、隐藏真实模型基准及最终独立软件验收仍未完成。
- 本地参考服务、合成测试和历史回放不构成机构生产验收或因果收益证明。完整 17 个工作包和 22 项审计发现未因本次发布关闭。
