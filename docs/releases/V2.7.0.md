# MARVIS V2.7.0

V2.7.0 为本地风控工作台新增受治理的数据接入、策略持续运营与机构参考接入流程，保留 V1 模型验证兼容边界。产品完整范围见 [路线](../roadmap.md)，逐项验收见 [手动验收手册](../development/手动验收手册.md)。

## 用户可见变化

- SQL 来源可以在工作台按表单或自然语言生成待确认查询；确认后注册数据集、预览并下载结果。查询受 SELECT 白名单、来源权限、行数和超时限制，旧版本提案及迟到结果会被拒绝。
- 字段别名和风险方向可显式确认并持久化；历史材料映射记录精确来源、期间和版本，未知字段与指标先澄清。
- 模型开发可以保留原所选候选，或在独立任务中明确重训完整 train/test 开发集。保留分支保留真实留出指标；重训子模型不虚构 test/OOT 指标。盲 OOT 支持独立封存、冻结后一次评估和原回执重放。
- Strategy Workbench 接通双人群、额度/定价/分群、历史与独立 asset/OOT 分析、可恢复搜索及持久草稿；策略交付的 Python、SQL、JSON 绑定同一冻结样本与规则版本。
- 参考在线决策支持安装、健康检查、激活、影子、请求重放和逐环境回滚；监控支持自然语言调度、冻结日历、补跑、通知回执、红灯处置及决策反馈。
- 决策回放、事件/覆盖来源和催收参考流程保留实体、时间、授权与原始执行证据；候选、批准、执行和观察结果分别呈现。
- 机构签名身份、资源授权、职责分离、跨实例交接和签名 Plugin/Workflow 的安装、权限审核、撤销、回滚接通设置与工作台。
- 通用机构适配器支持固定来源、模型登记、规则部署以及提交后丢响应的显式读回恢复；未配置时明确显示不可用，不产生外部请求。
- Agent 主动指令经过敏感检查，非法材料在出站前拒绝；调用与 token 预算、未知 usage 和费用状态保留。模型解释、记忆和报告叙事不改变平台计算指标。

## 兼容与支持范围

V1 模型验证继续使用 `RMC_SAMPLE_DF`、`RMC_TARGET_COL`、`RMC_ALGORITHM`、`RMC_SCORE_FN`；手动及 Agent 模式均保留，主分数一致性仍比较 Notebook 内存模型分与 PMML 分。数据字典 `importance` 必填，确认后的 Word/Excel 与多模型汇总继续按原合同生成。

- 强 worker 隔离限已验证 macOS backend 的非内置 input-only 计算。内置工具、Notebook kernel、API 与外部宿主进程不在此边界；Linux/Windows 此 backend 不可用。同主机恶意 UID 不在保证内。见 [隔离合同](../native-worker-isolation.md)。
- 跨实例模型传输只支持二分类原生 LR 的 median-imputer→StandardScaler→LR；额外预处理及其他模型族明确拒绝。见 [身份与同步说明](../institution-identity-and-sync.md)。
- 通用模型登记为不透明 `storage_only` 存储，远端参考部署为 `rule_only`，不提供通用远端模型评分服务。参考身份、服务、通知和催收不替代真实机构接入或业务批准。见 [机构适配器协议](../development/institution-adapters-protocol.md)。
- 用户主动指令仍须敏感检查；原样本、文件正文、凭据与报告全文不能作为模型出站内容。指标、结果和通过判定来自确定性工具及原件。

## 验证与验收状态

版本更新前的开发候选固定环境完整 V6 回归为 **16,191 通过、0 失败、0 错误、11 跳过**，共 16,202 个案例身份闭合；源码前后一致。跳过的 3 项浏览器 smoke 和 8 项真实模型诊断属于按需执行项目。该记录不替代 V2.7.0 版本更新后的完整发布检查、发布 SHA 的远端 CI 或用户正式验收。

发布 SHA 的完整本地检查、远端 CI、版本/tag 指向与工件 SHA-256，以 [GitHub Release 的实际发布记录](https://github.com/eddyzzl/marvis-risk-agent/releases/tag/V2.7.0) 为准；本文件不将版本更新前的开发检查等同于这些结果。用户可使用 [54 项手动检查](../development/手动验收手册.md)、[空白记录表](../development/手动验收记录表.csv)和[合成材料准备](../development/验收合成材料准备.md)在独立工作区验收。正式软件门保留至少 133 个不同案例、193 个执行槽位与原门槛，结果和复核签字尚待用户登记。

软件、业务效果与机构生产各自判定。历史材料须自行冻结时间、实体、标签成熟和独立比较门槛；本版本不承诺模型普遍优于已有模型。真实机构还需目标身份源/接口、批准 SLO、流量、告警回执、回滚与成熟业务结果。
