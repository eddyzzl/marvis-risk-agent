## Standards：工程约束

- 草稿保存只接受允许的报告叙事字段；KS/AUC/PSI 等指标仍由确定性代码计算。
- 保存、单份确认和整批确认继续核对任务、报告版本、草稿 ID、编辑版本和活动作业；失败不产生部分确认。
- 草稿保存在现有本地数据库消息 metadata；没有新增数据库 schema，也没有把正文放进浏览器持久化存储、审计 detail 或 Agent 记忆。
- Agent 提示明确区分已保存草稿和指标证据；提示中的可编辑文字不能覆盖计算结果。
- 旧确认 API 的兼容入口保留；Plugin / Tool / Hook / Workflow、策略候选认证和副作用授权边界不变。
- 保留桌面静态前端及既有主题；未引入框架或移动端范围。
- 发布使用干净的 `main` checkout 和 `scripts/release_push.py`，新建不可变版本 tag。

结论：下列发现修复后，本次差异未留下已知工程约束阻断项。安全扫描结果表示没有新增基线外问题或扫描器已知依赖漏洞，并不等于不存在漏洞。
