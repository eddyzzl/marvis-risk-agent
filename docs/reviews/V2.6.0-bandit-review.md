# V2.6.0 Bandit 新增查询审查

2026-10-08，使用远端 CI 相同的 Bandit 1.9.4 命令扫描完整 `marvis/`。旧基线过滤后剩余八项 B608 中危提示，均逐项回读了查询构造及输入来源。下表八项作为已审查误报追加到 `.bandit-baseline.json`，未重新生成或扩大原有基线，也未关闭 B608。生产代码未因本次基线审查改变。

| 来源 | 行 | 查询安全边界 |
| --- | --- | --- |
| `collection/execution_state.py` | 82 | 表名只来自函数内固定的三个字符串；不从请求、任务或数据列取得。触发器文本全部固定。 |
| `data/join_evidence.py` | 266 | `read_parquet` 的路径经 `sql_string_literal` 转义单引号并拒绝 NUL；文件还经任务归属、摘要和产物绑定认证。 |
| `data/join_evidence.py` | 270 | 使用上述已转义 relation；所有行数与边界值使用参数占位符。没有原始路径或请求 SQL 拼接。 |
| `data/join_evidence.py` | 277 | 使用上述已转义 relation；右侧成员行数使用参数占位符。其余表达式固定。 |
| `data/join_evidence.py` | 295 | JOIN 路径均经 `sql_string_literal`，左/结果 relation 由 `indexed_parquet_relation` 生成；源列名双引号成对转义。内部 ordinal 是固定前缀加下划线，别名索引仅来自 `range`。 |
